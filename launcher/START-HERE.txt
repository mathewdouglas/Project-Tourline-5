Project Tourline 5 - setup and play

Using RecompLauncher: open Easy Setup and select your extracted disc folder
(the one containing PS3_GAME). Leave the other inputs empty. Setup downloads
the official RPCS3 build (37 MB), uses it only to unpack the 01.04 update
already on your disc and decrypt its executable, then removes it. An RPCS3
window opens and closes by itself; leave it alone. Setup then imports and
verifies the required files. No separate update download, firmware or game
boot in RPCS3 is needed. Extract ISO files first, including PS3_GAME\INSDIR
(not just USRDIR).

Without RecompLauncher, use the built-in setup:

1. Run tourline5.exe. Keep the default storage folder, or choose an empty
   folder on another drive (including an external SSD).
2. Select your extracted Gran Turismo 5 US disc dump (BCUS98114, version 02.00),
   or its PS3_GAME folder. ISO files must be extracted first.
3. Choose Prepare from my disc. Setup downloads RPCS3 as described above,
   installs the update from your disc, decrypts a temporary copy of its
   executable and removes RPCS3 again. Nothing else to select or click.
4. Alternatively prepare with your own installed rpcs3.exe (setup presses
   its Install button and closes it), or import an existing 01.04
   installation and decrypted ELF.
5. Setup is remembered. Use tourline5.exe for every launch. F1 opens settings.

Your original disc dump stays where it is. Disc preparation installs the
bundled package into RPCS3, then imports a verified copy into your storage.
An existing newer GT5 installation is not replaced: use a separate RPCS3
folder or import matching 01.04 data. For custom RPCS3 game-data locations,
use the existing-installation route. Keep the disc folder available to play.
No game data, decryption keys, firmware or RPCS3 are included; setup's
temporary RPCS3 is the unmodified official build, checked against a pinned
SHA-256, and is deleted after a successful setup.

Saves, settings, shaders, installed data and logs use the selected storage.
Default: %LOCALAPPDATA%\ProjectTourline5
Use Open storage.cmd to find them. Initial video settings are 720p/2x MSAA;
DXC is the default shader compiler; FXC is available in F1. An incomplete GT5 install is finished
by the game itself on first boot and may take several minutes.

To change drives, close the game and run Change storage.cmd. Choose an empty
folder. Existing storage is copied and verified; the previous folder remains
as a backup. Reconnect an external drive before launching.
Change game files.cmd selects the source files again. Previous imported game
data is kept under backups/ when replaced; saves are kept separately.

Keep the entire player folder together, including assets/, pt5-release.ini,
the engine and its DLLs. The player folder itself can also live on your SSD.
The internal gt5.exe is the engine; tourline5.exe is the normal entry point.
Logs: selected-storage\logs\play.out and play.err. Setup failures: setup.err.

If the game crashes, freezes or stops with an error, tourline5.exe offers a
problem report: a ZIP of the logs, settings and basic PC details, saved under
selected-storage\logs\reports. Your Windows user name, profile folder and PC
name are removed; no game files, saves or screenshots are included. "Report
this on GitHub" opens a new issue with a summary filled in; attach the ZIP and
submit it yourself. Nothing is sent automatically.

tourline5.exe --check validates the saved setup and engine without launching
the game or opening dialogs. --setup, --choose-storage and --open-data are
the command-line equivalents of the shortcuts above.
